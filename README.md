# 내 안의 외계인

외부 라이브러리·서버·데이터베이스 없이 작동하는 반응형 MBTI 성향 테스트입니다.

## 실행

같은 폴더에 있는 `index.html`을 브라우저로 여세요. 인터넷 연결이나 설치가 필요하지 않습니다.

## 파일

- `index.html`: 시작·질문·결과 화면의 구조
- `styles.css`: 반응형 스타일과 CSS 외계인 캐릭터
- `script.js`: 16개 질문, 16유형 결과, 채점·화면 전환·공유

## 채점

E/I, S/N, T/F, J/P 축에 각 4문항입니다. 각 답변은 해당 방향에 1점입니다. 동점이면 해당 축의 마지막 답변을 사용합니다. 결과의 비율은 문항 선택 비율이며 검사 정확도나 확신도가 아닙니다. 이 테스트는 재미로 살펴보는 성향 테스트로 정식 MBTI 검사가 아닙니다.

## 결과 공유

웹 주소에서 실행하면 지원 브라우저의 기본 공유 메뉴를 사용합니다. 그 외에는 클립보드 복사를 시도하고, 권한이 없으면 직접 선택해서 복사할 수 있는 입력란을 보여줍니다. 로컬 파일에서 실행하면 접속할 수 없는 로컬 주소 대신 결과 문구만 공유합니다. 웹 공유 링크를 열면 해당 유형 결과가 표시됩니다. 공유받은 결과에는 본인이 답하지 않은 점수는 표시하지 않습니다.

## 저장

결과 유형과 축별 선택 수를 브라우저 localStorage에만 저장합니다. 답변을 외부로 전송하지 않으며 추적 도구와 외부 리소스가 없습니다. 다시 하기 버튼은 저장된 결과를 지우고 시작 화면으로 돌아갑니다. 저장이 차단된 브라우저에서도 테스트할 수 있습니다.

## 수정

질문과 결과 문구는 script.js의 QUESTIONS, RESULTS에서 수정하세요. 한 축에 4문항이 유지되도록 하고, 결과 키는 MBTI 코드(예: INFP)를 사용하세요.
